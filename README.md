# Metropolis 2140

A procedurally generated island megacity in the year 2140, in a single HTML file (three.js r128).
Orbit the skyline at day, dusk or night, fly a car through the towers, or hunt rogue AI.

Open `index.html` in a browser. Earlier present-day version: `archive/metropolis-v1.html`.
